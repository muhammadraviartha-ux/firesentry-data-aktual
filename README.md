# FireSentry — GPS Opsional, Semua Data Simulasi

Versi ini untuk demonstrasi/presentasi. GPS bersifat opsional: pengguna dapat memakai GPS, mengetik lokasi secara manual, atau tidak mengisi lokasi sama sekali.

Semua nilai cuaca, skor risiko, hotspot, dan prediksi foto adalah data contoh buatan. GPS hanya mengambil koordinat perangkat bila pengguna memberi izin; koordinat tidak membuat data simulasi menjadi data faktual. Tidak ada API cuaca eksternal yang dipanggil.

## Menjalankan
- Buka `index.html` melalui Live Server atau host statis seperti GitHub Pages.
- Untuk GPS di browser, umumnya diperlukan HTTPS atau localhost dan izin lokasi dari pengguna.
- Tanpa GPS, website tetap dapat digunakan dengan lokasi manual atau tanpa lokasi.
